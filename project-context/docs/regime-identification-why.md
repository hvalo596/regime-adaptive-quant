## 0. 一句话 + 层次

**一句话**：动量收的是"慢人"的迟到费，反转收的是"急人"的加急费；这两类付费者的强度**会变、而且变了会持续一段**，并在价格、成交量、持仓上留下**当期就看得见**的痕迹——所以可以用这些痕迹判断"现在谁在付钱"，再把权重偏向收费的那一边。四个环节（有对手方 / 会变且有粘性 / 看得见 / 来得及）任一断掉，课题就得出一个**具体的**否定结论，而不是"失败"。

```
地基（已有，核心站在它上面；地基动了核心要重写）
├─ 赚谁的钱：动量←慢人；反转←急人（白话文档）
├─ 有效性是动态的（Grossman–Stiglitz、Lo 的 AMH）：差异消失 = 否定结论
└─ 对象与顺序：期货（可双向）；中国先行，美国后置作独立验证

核心（本文；课题成不成立看这里）
├─ ① 为什么可行 = 四个可证伪条件同时成立（C1–C4）
├─ ② 如何来做   = 每一步只检验一个条件，按依赖顺序排
├─ ③ 怎么解释   = 谁付钱 / 为何付 / 换状态后怎样 + 对"非定义变量"做出预测
└─ ④ 为什么这样做可以 = 主张可分解、每个因子单独测、失败可归因

自由创新区（核心通过后放开；门槛 = 换完后四问仍答得出、底线不破，见 §5）
└─ 状态模型、配置算法、特征口径、窗口、工程实现……
```

## 1. 为什么可行：四个条件的合取

"可行"不是一句"市场不完全有效"就能打发的。把它拆开，**选策略有意义，当且仅当下面四条同时成立**。每条都写清：金融机制是什么、为什么在中国期货上有理由相信、怎么被否定、由哪一步检验。

### C1 利润有对手方（收益是补偿，不是噪声）

- **机制**：动量 = 信息逐步扩散、反应不足、羊群（Hong & Stein 1999；期货上的时间序列动量见 Moskowitz, Ooi & Pedersen 2012）。反转 = 给急于成交者提供流动性、收补偿（Campbell, Grossman & Wang 1993：高成交量后的价格变动更易回吐；Nagel 2012：流动性蒸发时反转收益上升）。
- **为什么还有钱**：完全有效不可能（Grossman–Stiglitz），纠错者受资金与风险约束（Shleifer & Vishny 1997 套利有限）。
- **否定方式**：两类策略在中国期货上锁定参数后，长期都没有显著收益且也无条件差异 → 说明样本内没有稳定付费者。这属于地基层，实验文档第 2 步会顺带看到。

### C2 对手方结构会变，而且**有粘性**（这是整个课题的铰链）

上一版只写了"此消彼长"，漏了更关键的一半：**光会变不够，必须变了之后持续一段**。如果付费者结构每天独立随机地变，过去的数据就对明天毫无信息，任何"识别"都不可能。状态能被识别，靠的就是粘性。

粘性从哪来（都是制度与资金的慢变量，不是情绪的瞬时噪声）：

| 慢变量 | 机制 | 让谁变多 | 为什么持续 |
|---|---|---|---|
| 杠杆与保证金周期 | 亏损→保证金压力→被迫平仓→价格再跌（Brunnermeier & Pedersen 2009 流动性螺旋） | 急人 | 去杠杆要分多天完成，螺旋自我强化 |
| 慢速资本 | 接盘/套利资本补充需要时间（Duffie 2010） | 急人的补偿变厚 | 资本回流滞后数周到数月 |
| 信息扩散与注意力 | 大的基本面变化（减产、政策）被层层消化 | 慢人 | 消化过程本身就是多日的 |
| **中国特有：交易所干预** | 调保证金、扩/缩涨跌停、限仓、提手续费，常是一段时间内连续出台 | 急人（被动减仓）或两类都被挤出 | 公告—执行—松绑有明确的时间段 |
| **中国特有：投资者结构** | 商品期货投机/散户成分高，国债期货以机构为主，股指期货 2015 年 9 月起受限多年（细节需核实） | 不同板块不同 | 结构变化以年计 |

还要纠正一个直觉：**慢人和急人不是同一群人的两种比例**，它们作用在**不同时间尺度**（反转看 1–5 日，动量看 20–60 日量级，具体待锁定），可以同时存在。所以"状态"在概念上是二维的——（慢人强度，急人强度）——四个象限：只有慢人、只有急人、都在、都不在（=有效）。这比"慢人多还是急人多"更准确，也直接决定代理变量要分两个尺度算（§1 C3、§2）。

- **否定方式**：按可观测状态分组后，风险标准化的"动量−反转"价差在组间没有显著且够大的差异；或独立片段的平均持续期太短（只有几天）。→ 结论：对手方结构在这个维度上要么不变、要么变得太快——这本身就是一个关于中国期货有效性的结论。
- **检验步骤**：第 2 步（存在性）+ 独立片段计数。

### C3 对手方结构在**当期**留下可观测痕迹（代理变量）

我们看不到"谁在场"，只能看到他们交易留下的东西。三类痕迹，离"谁"的远近不同：

| 痕迹类别 | 例子 | 对应谁 | 离"谁"多远 |
|---|---|---|---|
| 价格结构 | 方差比 VR(q)（Lo & MacKinlay 1988）、分尺度自相关；刑凯四维（系统水平/占比、特质水平/集中度） | 惯性→慢人；回弹→急人；四维说明冲击是共同还是局部 | 最远：只看到结果 |
| 量价与持仓交互 | 放量日的价格变动是延续还是回吐（Llorente, Michaely, Saar & Wang 2002：投机/信息型交易延续，对冲/流动性型交易回吐）；持仓量骤降+大跌（强平特征）；持仓量增+趋势（新资金进场） | 区分"带信息的卖"与"被迫的卖"——正好是反转最怕的接飞刀 | 中等：看到行为方式 |
| 参与者持仓 | 交易所每日会员成交/持仓排名（Tushare `fut_holding` 已验证可用，2005 年起有数据、早期较稀，INE 缺） | 头部席位多空变化、集中度 | 最近，但仍是"半直接"（见 §1.5） |

- **可用性约束**：所有代理只用 t 日及以前的数据算；分档阈值用滚动/扩展窗口，不用全样本分位数。
- **否定方式**：合成数据里，方法找不回已知状态；或在"无状态"数据上照样"发现"状态（幻觉）。
- **检验步骤**：第 1 步（合成数据 + 无状态对照）+ 第 5 步（打乱标签）。

### C4 来得及、划得来

- **机制**：付费窗口是有限的。急人的补偿在冲击后几天内就被收走；状态持续期若和检测延迟同量级，认出来时钱已经没了。
- **关键数**：状态平均持续期 ÷ 平均检测延迟；以及条件价差扣掉换仓成本（手续费 + 与波动/成交量挂钩的滑点；`fut_settle` 有手续费与保证金率）后的剩余。
- **否定方式**：C2 成立但比值接近 1，或扣成本后为零 → **边界结论**（状态存在但不可交易）。
- **检验步骤**：第 3 步（识别时效）+ 第 4 步（配置与信息价值三档）。

### 四个条件 → 四种结论

| 断在哪 | 结论 | 对"市场有效性"意味着什么 |
|---|---|---|
| 全部成立 | 正面：状态可指导选策略 | 中国期货在这些维度上有可预测的无效性起伏 |
| C4 断 | 边界：状态存在但来不及/成本吃光 | 无效性存在，但被交易成本和速度"保护"着——符合 Grossman–Stiglitz |
| C3 断 | 识别不行：状态可能存在，但我们的痕迹测不出 | 不能下有效性结论，只能说"这套代理不够" |
| C2 断 | 否定：付费者结构不变或变得太快 | 在这个维度上接近有效（或无效性是平的、不随状态变） |
| C1 断 | 地基不成立 | 两类策略本身在样本里无稳定收益 |

注意 C3 断和 C2 断**结论完全不同**，但在真实数据上表现一样（都是"没分出差异"）。区分它们的唯一办法是合成数据：在已知有状态的世界里能找回 → 方法没问题 → 真实数据没差异才可以归为 C2 断。这就是第 1 步不可省的根本原因。

### 1.5 诚实缺口：代理 ≠ 直接测量"谁在场"

把问题写成三个变量：Z = 真实的付费者结构（看不见）；X = 代理变量（看得见）；R = 策略收益。

- **我们能检验的**：X → R（按 X 分组，R 有没有差异）。
- **我们想主张的**：Z → X 且 Z → R，即"X 能预测 R，**是因为** X 反映了 Z"。
- **缺口**：X 可以不经过 Z 就和 R 相关。在中国期货上，下面这些通道必须逐一排除，否则"慢人多"可能只是数据制造的假象：

| 替代通道 | 怎么造出假"状态" | 排除办法 |
|---|---|---|
| 结算价平均化 | 中国期货结算价是成交量加权均价（股指/国债为最后一小时，商品多为全天），用结算价算收益会机械地产生正自相关（Working 1960 的平均化效应）→ 假"慢人" | 收益一律用收盘价；结算价只用于保证金/成本 |
| 涨跌停板 | 封板日没走完的行情挪到次日，机械地延续 → 假"慢人" | 标记触板日；做"剔除触板日"稳健性检验 |
| 换月拼接 | 未调整连续合约有跳空（IF 映射是当月合约而非主力，TL 连续码有污染，见 tushare 检查） | 用逐合约数据自建展期调整序列 |
| 同源循环 | VR 和动量收益都来自同一价格序列，窗口一重叠，"VR>1 → 动量赚钱"就是同义反复 | 状态只用 [t−w, t]，收益只取 (t, t+h]，中间可留隔离期 |
| 时变风险溢价 | 风险补偿本身随时间慢变，也会产生自相关，与"谁在场"无关 | 判别性预测：风险溢价通道不应依赖成交量/持仓变化（见下） |
| 买卖价差反弹 | 高频负自相关 → 假"急人" | 跳过一日再算；在周度尺度上复核 |
| 非同步收盘/夜盘 | 板块间收盘时间、夜盘归属不同，扭曲截面相关 → 四维失真 | 统一时间戳；四维先在同一板块内算 |

**怎么收窄缺口（四种手段，强度递增）：**

1. **多源一致**：价格痕迹、量价/持仓痕迹、会员持仓排名三类独立来源，要指向同一个 Z。只有一类说"急人多"不够。
2. **判别性预测**：每个替代通道和真机制对**某个变量**的预测不同。例：真"急人"状态下，反转收益应集中在**持仓量骤降 + 放量**的品种和日子；若只是价差反弹，跳过一日就消失；若只是涨跌停，剔除触板日就消失；若只是风险溢价，与量和持仓无关。
3. **准自然实验**：交易所的保证金上调、涨跌停扩板、限仓是**外生地推出急人**（被动减仓）。事前写下预测——上调后数日内持仓下降、短期反转补偿上升——再去看。2015 年股指期货受限是一次参与者结构的断点，可用来检验"投机者被挤出后映射如何变"（方向需事前写定）。
4. **投资者结构截面**：在中国内部就有结构差异——商品（投机成分高）、国债（机构为主）、股指（受限期前后不同）。机制若对，"状态→策略"的方向应**按结构差异预期地不同**；美国期货再作为市场层面的独立验证。

**收窄后仍然剩下的（必须在结论里明说）**：

- 会员持仓排名是**期货公司席位**，一个席位聚合成千上万客户；只有前 20 名；公开排名数据**不区分套保与投机**（不像美国 CFTC 持仓报告有商业/非商业之分）。所以它是"半直接"，不是"谁在场"的直接测量。
- 因此本课题能得到的最强口径是：**"与'谁在场'机制一致，并排除了已列举的替代解释"**，不是"测到了谁在场"，更不是"证明了因果"。准自然实验那部分最多到"准因果"。

## 2. 如何来做：每步只验一个条件，按依赖顺序

**检验对象先定死**：不是"动量赚不赚钱"，而是**风险标准化后的价差** D = 动量收益/其事前波动 − 反转收益/其事前波动（两腿各自先做波动率目标化）。理由：课题问的是**选哪个**，不是**下多少**；两腿都已按波动缩放后，"高波动时降仓"这条捷径就**从定义上**被排除了——D 在状态间若还有差异，只能来自"策略间重配"，这正是要证的东西。整体仓位缩放的贡献另算（信息价值分解里的"整体缩放"一项）。

| 步骤 | 检验 | 主检验量（草案） | 不通过 → |
|---|---|---|---|
| 0 机制→代理 | 前提 | 每个代理写一句"谁在场"+ 一条可否定假设；慢人/急人各按自己的尺度算 | 不进实验 |
| 1 场地 + 合成数据 | C3 的方法部分 | 已知状态的找回率；无状态数据上的幻觉率 | 方法不可信，后面全停 |
| 2 存在性（不用 HMM） | C2 | 按代理分档，D 的组间差异；block bootstrap 置信区间按片段抽；报告每档独立片段数 | **否定结论，止步** |
| 3 识别时效 | C3 实数据部分 + C4 前半 | 只用滤波概率；持续期 ÷ 检测延迟 | 边界结论（来不及） |
| 4 配置 | C4 后半 | 扣成本后 vs 无状态基准与 EWA；信息价值三档（无状态 / 滤波 / 上帝视角） | 边界结论（划不来）或"显式状态多余" |
| 5 防自欺 | 全部 | 隔离期、试验次数记账 + 缩减夏普、打乱标签、§1.5 的排除检验 | 前面的正面结果作废 |
| 6 失效分类 | 归因 | 识别 / 时效 / 映射 / 执行 / 新颖性，对应断在 C3 / C4 / C2 漂移 / 成本 / 样本外 | — |

**中国期货先行的落地要点**（数据已验证可得，见 tushare 检查）：收益用收盘价、逐合约自建展期；标记涨跌停与夜盘归属；股指期货 2015 年 9 月前后分段；四维先在**商品板块内**算（截面最宽），股指、国债先作单品种对照。

> 顺序本身是论证：C3 的方法可靠（第 1 步）才能把"没差异"读成 C2 断；C2 成立（第 2 步）才值得问来不来得及（第 3 步）；来得及才值得问划不划得来（第 4 步）。倒过来做，每一个结论都无法归因。

## 3. 怎么样解释：解释必须能被数据打脸

**每个状态、每个结果，必须答出三句**（沿用）：谁付钱？为什么付（迟到费还是加急费）？换了状态，故事怎么变？

**再加两条硬要求**——这是"解释"和"给标签起名字"的分界线：

1. **对非定义变量做出预测**。用 VR 定义的"急人多"状态，只说"这时 VR<1、反转赚钱"是循环论证。它还必须预测**没参与定义**的东西：持仓量下降、放量、头部席位净减仓、保证金刚上调……这些没对上，故事就是错的。
2. **讲失败故事**。每个状态都要说清这个策略**亏的时候是谁在赚**：动量崩溃时是抄底者和新信息；反转接飞刀时是知情卖方。答不出失败故事，第 6 步的映射失效就无法归因。

**示意：一张"状态卡"该长什么样**（非实证）

| 项 | 内容 |
|---|---|
| 名称 | 急人多（被动去杠杆） |
| 定义变量 | 短尺度 VR<1；系统水平高、占比高（共同冲击） |
| 谁付钱 / 为何 | 被强平、被迫减仓者付"加急费"；接盘者稀缺使补偿变厚 |
| 非定义预测 | 持仓量同步下降；成交放大；保证金上调或连续跌停后更常见；头部席位多头净减 |
| 失败故事 | 若同时伴随特质集中度高（单品种暴雷）且持仓不降，卖方更可能是知情者 → 接飞刀 |
| 证伪 | 剔除触板日、用收盘价后 D 的差异消失；或非定义预测不成立 |

**刑凯四维在这里的作用**：它把"波动高低"拆成"冲击是共同的还是局部的、步调齐不齐"，让状态卡的"失败故事"写得出来（共同冲击 vs 局部事件，正好对应急人 vs 知情者）。注意按草案口径，系统水平、占比、特质水平三者只有两个自由度，不能当三个独立特征（详见四维文档 A2）。

**结论的口气分三级**，不得越级：**相关**（X 分组下 R 有差）→ **机制一致**（非定义预测成立、替代通道已排除）→ **准因果**（保证金等外生事件下预测成立）。本课题目标是第二级，第三级是加分项。

## 4. 为什么这样子做可以：方法论的必然性

**理由一：主张可以分解，每个因子单独测，所以失败可归因。**
可用收益 ≈ 状态的理论价值（C1、C2）× 识别效率（C3、C4 的时效）− 执行成本（C4）。实验链恰好一步测一个因子：第 2 步测理论价值是否非零，第 3 步测效率，第 4 步测净值，信息价值三档把三者并排。少一步，就有一个因子混在别的因子里，"没赚到钱"就说不清是概念没价值、认不出来，还是成本吃光。

**理由二：价差 D 把"选策略"和"降仓位"从定义上分开。**
这是对"状态识别其实只是波动率目标化"这一最常见质疑的结构性回答，而不是事后用对照组去补。

**理由三："金融解释优先"有统计学理由，不是口号。**
独立的高风险片段只有十来个（刑凯的提醒）。十来个独立观测，**数据本身无法在众多模型之间做出区分**——状态数、窗口、特征组合都能调到好看。此时唯一不来自这批数据的信息，就是事前写下的经济机制：它限定了该看哪些变量、方向该是正还是负、在哪些非定义变量上必须对得上。机制在这里起的作用，等于用先验替代了缺失的样本。所以解释要**排在模型前面**，而且要在看数据前写下。

**理由四：每个缺失都对应一种具体的错。**

| 缺了 | 会犯的错 |
|---|---|
| 第 0 步机制 | 标签无法解释，失败无法归因 |
| 第 1 步合成数据 + 无状态对照 | C2 断与 C3 断分不清；幻觉率未知 |
| 第 2 步存在性 | 直接上 HMM，它总会给出几个状态 → 最大的假阳性来源 |
| 第 3 步时效 | 事后诸葛 |
| 第 4 步基准 + 三档 | 把降仓的功劳记给状态；失败无法拆因 |
| 第 5 步防自欺 + §1.5 排除 | 运气、泄露、结算价/涨跌停造出的假状态被当成发现 |
| 第 6 步失效分类 | 只有成败两种结局，学不到边界 |

## 5. 自由创新区：怎么放开、边界在哪

**入场券**：任何创新（换模型、换特征、换配置算法），换完之后四问仍答得出，且下面的底线不破。

**不可创新掉的底线**
1. 状态变量每一维能答"谁在场"，并能对非定义变量做出预测
2. 存在性（第 2 步）先于任何状态模型；复杂度每加一层要证明边际贡献
3. 检验对象是风险标准化价差 D，整体缩放的贡献单独报告
4. 只用滤波概率；状态窗口与收益窗口不重叠
5. 必须有无状态基准与绕过状态的 EWA 对照
6. 所有数字带误差范围、报告独立片段数与试验次数；否定结论如实报告

**区内可自由试的（举例，非任务）**：规则阈值 / HMM / sticky-HSMM / 在线变点；把会员持仓排名做成状态变量（默认只作验证工具）；Llorente 式量价交互作为"急人 vs 知情者"的判别维；保证金调整事件研究；直接对价差 D 建状态模型；不动区间宽度随成本与置信度变化的推导。
