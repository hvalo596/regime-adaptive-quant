## 摘要

本文在扣除事先固定的交易成本、波动率匹配之后，问：**认出状态能否提高组合夏普，相对 50/50、纯动量、近期表现（TP60/EWA）？** 配置映射含概率加权、熵惩罚与不动区间；分解缩放账户与择时/倾斜账户以区分「κ 缩放」与「MOM–REV 重配」。真实数据上主检验族四次比较 Holm 均不显著；滤波亏损主要来自**方向**（长期偏反转而反转腿无条件为负），择时账户近零。合成三档显示：真值信号极有价值，但滤波只兑现一小部分。结论定位于**概念未在数据上变现**（非证明概念无效）。复现 §8；审稿人自检 `internal/journal-reporting-referee-qa-2026-11-24.md`。

## 1. 结论一页

1. **没有任何状态策略在真实数据上打败无状态基准。** 预先登记的主检验族（带熵惩罚的滤波策略，按相同波动匹配，基本成本 1×，对比 EW50、MOM、TP60、EWA 四个无状态/近期表现基准）里，滤波策略的夏普为 −0.59，比 EW50+VT（0.16）低 0.74（95% 区间 [−1.07, −0.37]），Holm 校正 p 全为 1.0。第 2 步的规则策略夏普 0.02，比 EW50+VT 低 0.14（[−0.46, +0.18]）。
2. **原因主要不是"识别得慢"，而是方向。** 滤波信号平均 $s=-0.53$（几乎总偏向反转，第 3 步 §5.3：高均值状态被标成了基线），而反转腿在这 20 年的无条件夏普是 −0.6（毛收益 −6.9%/年，成本 3.4%/年）。把这一倾斜分离出来，择时账户（$\mathrm{Cov}(s,D)/2$）全部接近 0：规则 −1.4%/年、滤波 +0.2%/年、近期表现 TP60 −0.8%/年、EWA +0.4%/年（均为相对 EW50 的年化收益贡献，腿目标波动 10%）；倾斜账户则从 −7.2%（硬滤波）到 +8.6%（学习的倾斜）。**状态的"择时价值"在真实数据上读不出来。**
3. **真正赚钱的是无条件的动量溢价。** 动量腿（同波动匹配，MOM+VT）基本成本 1× 下夏普 1.12（95% 区间 [0.65, 1.59]），而 EW50+VT 只有 0.16（[−0.24, 0.59]）；用数据估计倾斜的"学习的倾斜"策略夏普 1.09，与 MOM+VT 的差 −0.03（[−0.06, 0.00]）——它只是学会了"一直做动量"，择时账户 +0.1%/年。需要强调：MOM-only 是用样本后见之明挑出来的基准，不是事先可交易的状态策略；且这一溢价在后半窗口明显衰减（MOM+VT 夏普前半 1.66、后半 0.60）。
4. **EWA 与近期表现（"完全绕过状态"）**：EWA+VT 夏普 0.79（[0.32, 1.30]）显著高于 EW50+VT，但仍低于 MOM+VT 且同样靠无条件动量倾斜（平均 $s=+0.64$，择时账户 +0.4%/年）。**H9**：在 $D_{t+1}$ 对 $s_t$ 与近 60 日表现的回归里，$s$ 的系数规则 −2.5e-4（[−8.2e-4, +3.0e-4]）、滤波 +2.1e-4（[−6.0e-4, +10.6e-4]），近期表现的系数也都不显著；即"显式状态不比近期表现多出信息"得不到支持，**但近期表现自己在真实数据上也没有信息**。
5. **信息价值三档（合成世界，已知真相）**：状态这个概念本身在存在时很值钱——真值信号比无状态高 1.1–3.2 个夏普单位（基本成本、波动匹配）；但识别方法只拿到其中的 −6% 到 46%（滤波），规则拿到 37% 到 75%，近期表现类基准拿到更多。真实数据只有①②两档可比（无真值）：无状态 0.16，滤波（守卫版）0.14，两档相同。
6. **边界结论**：真实数据没有找到值得为状态付成本的证据；合成世界给出的边界是：只有当状态效应 $\ge0.15$ 且持续约一年时，滤波策略才有约 50% 的概率在基本成本下显著打败无状态基准，而同样条件下"规则 + 近期表现"类简单办法更好。**这不是"状态没有价值"的证明**（第 2、3 步的功效限制仍在），也不是"显式状态是多余的"的证明，只是在已有数据上没有看到它们的价值。

## 2. 设计

**策略菜单**（全部写成对两条已缩放到同一目标波动的腿的选择信号 $s_t\in[-1,1]$，$W_t=\mathrm{scale}_t\,[\tfrac{1+s_t}{2}W^{MOM}_t+\tfrac{1-s_t}{2}W^{REV}_t]$；决策日 $t$ 的权重赚 $t+1$ 的收益）：

| 类 | 策略 | 说明 |
|---|---|---|
| 无状态 | EW50、MOM、REV | $s=0$、$+1$、$-1$ |
| 无状态 | EW50+VT | 对 50/50 做波动率目标化（60 日、上限 3 倍、滞后一日）：文档说的"一行代码"基准 |
| 近期表现 | TP60 | $s=\tanh(t_{60}/2)$，$t_{60}$ 为 $D$ 的近 60 日 t 统计量 |
| 近期表现 | EWA | Hedge：$s=\tanh(\eta(S_M-S_R)/2)$，$S$ 为按 $\lambda=0.99$ 折现的累计腿收益（以日目标波动为单位），$\eta=0.5$（事先固定；网格见 §5） |
| 状态 | RULE | 第 2 步滞后带的 $s$ |
| 状态 | FILT-HARD / SOFT / PEN | 滤波概率：$\mathbf 1\{p>0.5\}$ 之差；$p^M-p^R$；PEN = SOFT×$(1-H/\ln4)$，$H$ 为四象限熵（文档 §4.6 的权重，**主策略**） |
| 状态 | FILT-BAND | PEN 加不动区间（目标变化 >0.3 才调整） |
| 状态 | LEARNED | 倾斜由数据估计：四象限的状态内 $D$ 均值各自向池化均值收缩（权重 $n_k/(n_k+250)$），再 $s=\tanh(\hat m/(\mathrm{sd}(D)/\sqrt{250}))$ |
| 状态 | FILT-PEN-G / FILT-HARD-G | 第 3 步的退化守卫版（**事后**加入，不进主检验族） |
| 上限 | ORACLE | 植入的真值状态（只有合成世界） |

**波动匹配**：每个策略都有"+VT"版本，缩放到同一事前波动（用自己未缩放收益的 60 日滚动标准差，滞后一日，上限 3 倍）。因为状态择时最容易退化成"吵的时候少持仓"，**主比较一律在 +VT 版本之间做**。

**成本**：单边成本 = 0.5 bp 手续费 + 0.02×事前日波动（流动合约 1–2 个最小变动价位，约 3.5 bp）。**在看任何第 4 步结果之前固定**；网格 0、0.5、1、2 倍。第 1 步草案的成本（1 bp + 0.05σ ≈ 8.5 bp）落在 1× 与 2× 之间。含展期的两笔成本没有计入（展期在调整收益里不产生换手，展期成本对所有策略相同）。

**账户**（文档 §4.5 的恒等式 $P-\tfrac12(x^M+x^R)=\tfrac12 sD$）：选择账户 = 倾斜（$\bar s\bar D/2$）+ 择时（$\mathrm{Cov}(s,D)/2$）；只有择时是关于人群的信息。缩放账户（降仓）由 +VT 版本隔离。

**推断**：夏普的区间与差值用配对的平稳块自助（块长 40 日，1 000 次）；主检验族只有 4 个比较（FILT-PEN+VT 对 EW50+VT、MOM+VT、TP60+VT、EWA+VT，基本成本），Holm 校正；全部比较（约 7 种信号×4 个基准×含/不含 VT×2 档成本×6 个面板）计入 `comparisons_*.csv`，不做事后挑选。

| 动量 | +12.6% | 1.3% | +11.3% | 0.19 |

反转腿的毛收益为负，成本放大亏损；文档 §4.5 的盈亏平衡强度 $R_{BE}$ 在这里没有意义（$R<0$ 的区间内永远赚不回成本）。**反转在这个样本里本身就不是正期望**，所以"在急人状态里切到反转"没有可以收割的东西，除非存在被平均掩盖的、局部为正的状态（第 2、3 步没有找到）。

### 5.5 稳健性与试验数

- **子区间**（1× 夏普；前半 2006-06-27 至 2016-08-30，后半 2016-08-31 至 2026-11-23）：MOM+VT 1.66 / 0.60；EWA+VT 1.46 / 0.13；EW50+VT 0.39 / −0.07；RULE+VT 0.57 / −0.53；FILT-PEN+VT −0.51 / −0.66；FILT-PEN-G+VT 0.36 / −0.06；LEARNED+VT 1.64 / 0.55。**所有正的结果都在后半窗口大幅衰减**，后半窗口里只有 MOM+VT 与 LEARNED+VT（后者就是动量）为正。
- **EWA 网格**（`ewa_grid_commodity.csv`，12 个设定，作为额外试验计入）：1× 夏普 0.51–0.88，事先固定的设定（$\lambda=0.99$，$\eta=0.5$）为 0.79，不是最优也不是最差。
- **面板一致性**（1× 夏普 EW50+VT / MOM+VT / EWA+VT / RULE+VT / FILT-PEN+VT / 守卫）：黑色（7.9 年）−0.09 / 0.45 / −0.54 / −0.09 / −0.17 / −0.19；有色（6.8）0.33 / 0.54 / 0.10 / −0.33 / 0.00 / 0.33；能化（12.7）−0.09 / 0.50 / 0.09 / −0.11 / −0.19 / −0.09；农产品（16.0）−0.50 / −0.05 / −0.48 / −0.64 / −0.58 / −0.55；股指（6.8）0.22 / 0.47 / 0.12 / 0.22 / −0.09 / 0.22。动量在 4/5 个面板为正，在所有面板里状态策略都不优于无状态基准。
- **试验数**：信号 7 种 × 4 个基准 × 含/不含 VT × 2 档成本 × 6 个面板（含商品）的配对比较全部写入 `comparisons_*.csv`（约 670 条）；预先登记的主检验族 4 个；事后加入的守卫变体与 LEARNED 的比较明确标为事后。

## 6. 读法与边界结论

1. **"没有看到状态的价值" ≠ "状态没有价值"。** 合成世界表明：在状态存在时，把它用对价值很大（真值信号比无状态高 1.1–3.2 个夏普单位），但识别方法只拿到一部分，且简单的近期表现类办法拿得更多。真实数据上第 2 步没有检出状态，所以第 4 步的"没赚到钱"归因于第一类原因——**概念价值在这些数据里读不出来（③≈①的可能性不能排除）**，而不是"状态有价值但认不出来"：若是后者，应当看到真值与无状态的差大、滤波与无状态的差小，而真实数据没有"真值"可用，这一归因只能由第 2 步（找不到状态）提供，是间接的。
2. **主要风险是把"押动量"当成"识别状态"。** 这个样本里动量腿无条件夏普 1.1，任何平均偏向动量的信号都会"显著打败 EW50"。本报告的分账（倾斜 vs 择时）与对 MOM 的对照就是为此设计；任何关于状态价值的主张都必须以择时账户或对 MOM+VT 的对照为准。
3. **成本不是主因**：在 0 成本下状态策略同样没有优势（FILT-PEN+VT 0.0× 夏普 −0.24；守卫版 0.49，与 EW50+VT 的 0.50 相同；RULE+VT 0.31 低于 EW50+VT）。
4. **样本里的唯一稳固事实**是：动量溢价为正且在后半窗口衰减，反转腿为负。这对"状态指导选策略"的含义是：动量腿占优的世界里，选择问题退化成"要不要在某些时期不做动量"，而本样本里没有可识别的信号告诉我们何时不做。

## 7. 偏离与局限

| # | 内容 | 理由 |
|---|---|---|
| S4-1 | 成本模型 0.5 bp + 0.02σ 在结果之前固定，网格 0–2 倍 | 草案成本（1 bp+0.05σ）在 1×–2× 之间；没有最小变动价位表，滑点只能估计 |
| S4-2 | 主比较一律用波动匹配版本；没有再做"状态降仓"的 $\kappa_0$ 缩放账户 | 状态 Ⅳ 的 $\kappa_0=0.5$ 在第 2 步已经因为状态 Ⅳ 不"静默"而失去前提；缩放账户被 +VT 版本整体吸收 |
| S4-3 | 倾斜/择时拆分，主检验族对 EW50/MOM/TP60/EWA | 第 1 步 D1 已指出未中心化的选择账户会把无条件溢价当成择时；N0/N1 里夏普对比 EW50 的假阳性高达 47–58% |
| S4-4 | LEARNED 的尺度（$\tanh$、$n_0=250$）和 EWA 参数（$\lambda=0.99$，$\eta=0.5$）是预先设定的 | 文档要求"向整体估计收缩"但未给尺度；EWA 参数的网格已作为额外试验报告 |
| S4-5 | 守卫变体事后加入 | 主状态策略（文档 §4.6）在真实数据上因退化而偏向反转；守卫是为了回答"若不让退化模型下注，结果是否 ≈ 无状态"，不进主族 |
| S4-6 | 不动区间只实现了 FILT-BAND（0.3 的带宽） | 文档要求；带宽没有数据驱动的选择，结果与 PEN 相同 |
| S4-7 | 真值档（ORACLE）只在合成世界 | 真实数据没有真值；效率用合成的 11%–46%（滤波）来读 |
| S4-8 | 贵金属、国债面板不估计；行业、股指面板 <20 年 | 品种数与上市时间 |
| S4-9 | 没有 HMM 以外的在线学习（如 EXP3 变体）与资金容量分析 | 超出第 4 步范围；容量需要持仓/成交深度数据 |

局限：合成世界的比例有 60 次模拟的抽样误差（±6 个百分点）；夏普区间对 20 年样本仍很宽（动量 [0.65, 1.59]）；真实反转腿的亏损使"选择账户"不对称，不能把结论推广到反转有正期望的样本（如更早的数据或美国期货，后者按计划后置）。
