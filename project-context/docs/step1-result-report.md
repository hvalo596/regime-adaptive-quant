## 2. 做了什么

1. **状态变量**（`statevars.py`）：标准化收益（60 日、±5 截断、分母只用 t−1 及以前）；留一法等权共同因子与 60 日滚动回归；$M_t$、$R_t$、$R^{gap}_t$（策略匹配自相关，商品面板合并、每品种窗口内去均值）；$C_t$（异常比 $u$、HHI、扣零基准 $h_0$）与标记集合 $\mathcal F_t$；$V_t$、$\Phi_t$、$\Phi^\perp_t$ 与 750 日滚动 z。
2. **状态机**（`statemachine.py`）：双阈值（1.28/0.5）+ 最短驻留（动量 $H$、反转 $\max(h,5)$）；$s_t=\delta^M-\delta^R$；四象限；知情叠加。
3. **回测引擎**（`backtest.py`、`eventengine.py`）：腿 = 标准化收益符号信号 → H 日分批 → 逆波动定仓 → **腿层面再缩放到同一目标波动**（这是恒等式成立的前提）；$w^{MOM}=\tfrac12(1+s)$、$w^{REV}=\tfrac12(1-s)$、$\kappa_0=0.5$、剔除 $\mathcal F$；成本 = 手续费 + 与波动挂钩的滑点；另有逐日流式的第二套实现，两套代码互不共用。
4. **合成世界**（`world.py`）：慢人（吸收缺口 $G$）、急人 + 做市接盘者（库存 $B$）、知情者（永久漂移）、半马尔可夫切换；N0z（零动态）、N0（常参数）、N1（只有波动在变，波动因子标准差 0.3→0.9）、N2（风险结构马尔可夫切换：共同份额 0.06/0.15/0.45、特质方差集中在 3 个品种，核心参数为零）、**N2c**（同上，核心为非零常参数）、N2b（集中但公开：个别品种波动 ×4 持续 8 日、无漂移）、N3（AR(1) 风险溢价，持续性 0.998）、N4（买卖价差反弹 ±0.25σ、结算价=日内均价）。成交量、持仓、成交额也按 §7.1 生成（给第 2 步的非定义检验做合成真值）。
5. **检验**（`inference.py`、`hypotheses.py`）：Θ 检验（块自助 + 循环平移）；H5 事件级检验；δ 与环境变量的关联检验。
6. **一次性校准**（`nullcal.py`）：偏差 $b$、标准误倍数、C 的零分布，用零动态世界一次求出后固定。

读法：理论文档的 κ 与 Isserlis 标准误公式在肥尾、波动聚集下基本准确（倍数 0.9–1.04）。**偏差 $b$ 不小**：≈ $-\sqrt{LH}/T$（M-B −0.055，约 1.5 个标准误；R-A −0.091，约 1.6 个标准误）。不扣除的话，R-A 在空世界里 $R=-\hat\rho$ 会长期读成 +0.09，急人几乎"永远在场"。文档要求扣除的做法是对的，但"小样本负偏差"的措辞低估了量级。

### 3.2 闭式解（§7.3）与样本

单一象限世界（驻留无穷长）里，偏差校正后的样本 ρ 与闭式解之比：M-B 在象限 Ⅰ 0.82、Ⅱ 0.92；R-A 在象限 Ⅱ 0.88；M-A 0.89；R-B-gap 0.88。象限 Ⅳ 全部 ≈0（|样本| ≤ 0.003）。**样本比闭式小 10%–20%**（标准化与截断削弱了肥尾下的相关）。两处偏离较大：Ⅰ 中 R-A 样本只有闭式的 0.62（慢人对短尺度的污染被削弱），Ⅲ 中 R-A 为 1.43（Ⅲ 的参数极端，见 D11）。

## 4. 尺子的灵敏度（对第 2 步结论怎么读）

- 假阳性率没有问题（≤5%），所以第 2 步若得出"找到状态"，不会是尺子编的（至少在这套合成机制下）。
- **灵敏度有限**：在 2500 日 × 40 品种、Θ 判定规则下，Δρ=0.15 且状态驻留 300 日时检出率 66.7%；驻留按文档默认（120/20/30/120）时只有 24.7%；Δρ=0.10 时分别为 35.3%、11.3%。换言之：**如果真实世界的状态效应是文档示意的 0.10–0.15、且急人状态像文档假设的那样只持续 2–4 周，第 2 步多半检不出来**，此时"没检测到"只能写成"功效不足"，不能写成"状态不存在"。
- 慢人侧可以识别的前提是状态持续一年左右（M-B 窗口 200 日、中位延迟 85 日）；急人侧靠价格痕迹只在持续 ≥ 1–2 个月时才稳定（R-A 延迟 31 日）。

## 5. 对理论文档的修正（偏离清单，每条都有理由）

| # | 文档原文 | 实现 | 理由与证据 |
|---|---|---|---|
| D1 | 主检验量 $\Theta=\mathbb E[s_tD_{t+1}]>0$ | **判定用中心化形式 $\mathrm{Cov}(s_t,D_{t+1})$**；原式同时报告 | $s_t$ 的均值不为 0、$D$ 的均值不为 0（例如动量有无条件溢价）时，$E[sD]=\mathrm{Cov}+E[s]E[D]>0$ 与择时无关，是配置倾斜。N0 中朴素 Θ（自助下界>0）假阳性 68.5%，N2b 67.8%，N1 50%；中心化后全部 ≤4.25%。文档 §8 的"循环平移零分布"本身已经把 $E[s]E[D]$ 扣掉，我只是让点估计和自助区间也用同一个量 |
| D2 | $\mathcal F_t$ = 累计占 $u$ 总质量 ≥50% 的最少品种且每个 $u\ge4$ | **按对集中度超额 $\mathrm{HHI}-h_0$ 的贡献 $p_i^2-h_0/N$ 累计 ≥50%** | 截断 $u\le25$ 时单个品种最多占 $25/(25+N-1)$ 的质量，$N\ge27$ 时不可能达到 50%，文档规则在 30–40 个品种的面板上永远标不出任何事件（实测首版 F 几乎恒空）。贡献版是同一思想（"对 C 贡献最大的品种"）且可行 |

## 6. 已知局限与未做的事

1. **没有用真实数据校准合成世界**（没有 token）。偏差 $b$、标准误倍数、C 的零阈值都基于风格化参数；第 2 步拿到数据后用 `nullcal.calibrate(mask=真实缺失模式)` 重做，再运行第 2 步。
2. 成交量、持仓、成交额的生成机制是假设（§7.1 已声明），只用于第 2 步代码的合成真值测试，不是证据。
3. 检出率用 150 次模拟，二项标准误约 ±4 个百分点；假阳性率用 400 次，±1 个百分点。
4. 状态 Ⅲ 在识别上几乎不可用（见 D11），第 2 步的 H3 因此会天然功效不足。
5. **Θ_c 有一个小的负的有限样本偏差**：400 次空模拟里 Θ_c 均值为 −2e-5 至 −3.5e-5（空分布标准差约 1.3e-4，即 0.15–0.25 个标准差，t 约 −3 到 −5）。原因：$s_t$ 由 $M,R$ 的乘积窗口构成，这些乘积含有过去几十日的腿收益，所以 $s_t$ 与**过去**的 $D$ 正相关，而样本协方差减去 $\bar s\bar D$，于是整体偏低。它让单侧检验略保守（假阳性点估计偏低），对 0.0009 量级的 Θ_c 影响不到 4%；流水线级零分布含同样的偏差，所以第 2 步的 $p_{pipeline}$ 不受影响，但读单个 Θ_c 为负时不要当成信息。
6. 阈值 1.28/0.5、$\kappa_0$、窗口等全部沿用文档草案值，没有为通过标准调整任何阈值；改动的只有 D1–D9 列出的实现细节，每个都是由一次失败的诊断驱动的。
