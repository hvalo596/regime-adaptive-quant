## 一句话核心

**识别状态 = 判断现在市场里「慢人」多还是「急人」多，从而偏动量（赚慢人）还是偏反转（赚急人）；两类人此消彼长，所以相对优势会随状态变，这就是选策略的依据。**

### 先把层次摆明（ieki 补充：这四问是实验的核心）

```
课题
├─ 地基（前面做的，已有）—— 不是核心，但核心站在它上面
│   ├─ 赚谁的钱：动量赚慢人、反转赚急人（白话文档）
│   ├─ 有效性是动态的：差异消失 = 否定结论，也算结论（AMH）
│   └─ 对象与顺序：期货、中国先行、美国后置作独立验证
│
├─ 核心（本文，钉死的东西）—— 课题成不成立看这里
│   ├─ ① 为什么可行

│

    ├─ 配置方法：概率加权、收缩、不动区间、EWA 对照 ……
```

**怎么用这个层次：**
- 地基动了，核心要重写；核心动了，整个课题要重新立论。
- 自由创新区**可以随便换、随便试**，唯一的门槛是：**换完之后，核心四问仍然答得出**（尤其「谁付钱」「换状态后故事是否成立」）。答不出的创新，不管拟合多好，不收。
- 所以创新的自由是**有边界的自由**：边界就是核心里的几条硬约束（见 §4 末尾的「不可创新掉的底线」）。

## 1. 为什么可行（可行性）

- **经济机制：两类对手方此消彼长，不是永远同在**
    - 慢人（反应不足、羊群、拆单大资金）多 → 价格有惯性 → 动量有钱收
    - 急人（恐慌、强平、限时调仓）多 → 价格被砸过头再回弹 → 反转有补偿收
    - 两类人的数量随信息扩散速度、情绪、流动性、套利资金松紧而变 → **优势在两种策略之间摇摆**，这是「选策略有意义」的唯一根基
    - 若两类人永远一样多（或永远都没有），状态就没有信息，课题不成立——这正是要检验的
- **可观测代理：我们看不见「谁在场」，但能看见他们留下的痕迹**
    - 慢人/急人 → 收益自相关结构（方差比 VR>1 / <1），直接对应策略利润来源
    - 冲击是共同的还是局部的、同步还是各讲各的 → 刑凯四维（系统水平、系统占比、特质水平、特质集中度），见[四维文档](/cursor/stores/bc-d8a1a980-0799-49a7-8a92-335d96978291/docs/kai-dims-and-experiment-steps.md) A 节
    - 代理只用**当期及之前**的数据算，保证实盘能用
    - ⚠️ 诚实风险：代理与「谁在场」之间是**推断**，不是直接测量。VR>1 也可能来自别的原因（风险溢价时变、非同步交易等）。这座桥必须靠 §2 的第 2、5 步去检验，不能当成已知
- **不是假设永远有超额，而是假设「相对优势随状态变」**
    - 弱命题（我们只证这个）：不同状态下，动量与反转的条件表现**有显著且够大的差异**
    - 强命题（我们不主张）：永远能赚钱
    - 差异显著、扣成本后仍可用 → 正面结论；显著但扣成本/延迟后没了 → 边界结论；差异本来就不显著 → 市场在样本内较有效，**否定结论**。三种都算答案（见白话文档第 3 节表格）
- **样本约束下为何仍可行**
    - 有效样本 = 独立状态片段数（约十来次），不是天数 → 不能上高维
    - 所以：**低维（4+1 维）、先规则后 HMM**；规则型（分位数分档）几乎没有参数，样本再少也估得动；HMM 只在低维上跑，且排在存在性检验之后
    - 样本少的代价要说清：稀有阶段估不准，对应识别失效 + 新颖性失效，写进结论而不是回避

## 2. 如何来做（操作链）

按实验 0–6 步压缩成**做的顺序**，每一环只在前一环成立时才往下走。中国期货（股指/国债/商品）先行，美国后置作独立验证。

```
机制 → 代理变量 → 存在性 → 识别 → 配置 → 防自欺 → 失效分类
(0)     (0)        (2)      (3)    (4)     (5)       (6)
              (1 搭场地 + 合成数据排练，贯穿其中)
```

- **机制 → 代理变量（第 0 步）**：每个变量写一句「谁在场」+ 一条**可被否定**的假设
- **存在性（第 1–2 步）**：先在合成数据里验证「方法不会凭空找出状态」，再在真实数据上**不用任何模型**，只做分档，看动量/反转的条件表现差异是否显著（block bootstrap，报告独立片段数）。**这是生死线**：不显著 → 直接写否定结论，后面不启动
- **识别（第 3 步）**：只用滤波概率，能多快认出？关键数 = 状态平均持续期 ÷ 平均检测延迟
- **配置（第 4 步）**：认出之后怎么配权；必须赢过无状态基准（波动率目标化等）和绕过状态的 EWA；信息价值三档回答「状态值多少钱、我拿到多少」
- **防自欺（第 5 步）**：隔离期、多重检验、打乱标签、压力测试
- **失效分类（第 6 步）**：识别/时效/映射/执行/新颖性，说清在哪坏

> 核心要点：**顺序本身就是论证**。后一步的结论只有在前一步通过时才可信，所以不能跳、不能倒。

## 3. 怎么样解释（解释标准）

**每个状态、每个结果，都必须能答三句：**

1. **谁付钱？**（这个状态下，慢人还是急人在给我付钱；对面会不会其实是知情者）
2. **为什么付？**（迟到费？加急费？——对应哪条机制）
3. **换了状态，故事还成立吗？**（换到另一个状态，这个策略为什么不赚了/亏了；对手方画像怎么变的）

- **刑凯四维如何服务解释**：把「波动高低」拆成「谁在场」——共同冲击大不大、步调齐不齐、信息冲击普遍还是局部、惯性还是回弹。每一维都对应一句人话，所以状态能落到「慢人多/急人多/对手方消失」。第 6 步的**映射失效只有状态可解释时才能归因**
- **黑箱拟合不算成功**：回测曲线再好，答不出上面三句，就是「舍本逐末」，不收
- **解释同样要接受检验，不是事后讲故事**：解释必须产生可检验的预测（例如打乱状态标签后收益应消失；换到另一个市场，方向应按投资者结构的差异而变）。讲得通但没有任何检验方式的解释，不算
- 注意区分：**解释 ≠ 因果已证**。我们能做到的是「机制自洽 + 多重检验下仍然存活」，不是证明因果。结论里要用这个口气

## 4. 为什么这样子做才可以（方法论必然性）

**原则：金融解释优先于模型。** 模型只是把「已经能解释的状态」自动化识别的工具，不能让模型替我们决定「状态是什么」。下表对照：缺哪一步，会犯什么错。

| 缺了 | 会犯的错 |
|---|---|
| 机制 / 代理（第 0 步） | 得到无法解释的标签，对不上「赚谁的钱」；失败了无从归因 |
| 合成数据 + 无状态对照（第 1 步） | 真没有 / 没找到 / 编出来，三者无法区分；幻觉率未知 |
| 存在性（第 2 步） | 直接上 HMM，它必给你几个状态，「拟合很好」成了假阳性来源 |
| 识别延迟（第 3 步） | 事后诸葛：回测漂亮，实盘认出来时状态已结束 |
| 无状态基准 + 信息价值三档（第 4 步） | 把「高波动少买点」的功劳记给「状态识别」；失败原因无法归因（状态没价值 vs 认不出） |
| 防自欺（第 5 步） | 试几百种挑最好的，其实是运气或泄露 |
| 失效分类（第 6 步） | 只有成败两个结局，学不到东西，也讲不清边界 |

**不可创新掉的底线**（自由创新区的边界，换什么模型都不能破）：
1. 状态变量能答「谁在场」，低维、近似正交（实测，不预设）
2. 存在性先于模型；复杂度每加一层要证明边际贡献
3. 只用滤波概率，不用平滑/Viterbi 进回测
4. 必须有无状态基准与「绕过状态」的对照
5. 所有数字带误差范围；否定结论如实报告

**为什么「金融解释优先」不是口号**：数据里的状态数、窗口、拟合优度都可以被调到好看，唯一不能被调出来的，是「谁付钱」这个因果故事在换状态后是否自洽、是否被检验。所以解释是**最后的防线**，必须排在模型前面。
