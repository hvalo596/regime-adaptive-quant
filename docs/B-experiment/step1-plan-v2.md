# 第 1 步方案 v2：按 [状态构建理论](../A-idea/theory/state-construction.md) 重写

> 取代 2026-11-18 的旧方案 `step1-plan.md`（旧方案围绕 6 个 VR/刑凯代理指标的"幻觉率/功效"，与已批准的理论不一致；旧文件未改动，仍留在原处）。
> 日期：2026-11-21。结果见 [step1-result-report.md](./step1-result-report.md)。

## 1. 第 1 步回答什么

不回答"真实市场有没有状态"，只回答**尺子可不可靠**：

1. 在"谁在场"已知的合成世界里，§3 的变量能否把 4 个象限 + 知情叠加找回来；
2. 在**没有**策略状态的世界（N0、N0z、N1、N2、N2b、N3、N4）里，整条流水线（变量 → 滞后带状态机 → $s_t$ → Θ 检验）会不会编出状态（假阳性率 ≤ 5%，即 H13）；
3. 识别延迟是否与 §4.3 的 $d^*$ 公式对得上；
4. 回测引擎本身没有偷看、没有对账差异。

## 3. 策略参数（已批准，写死在 `config.py`）

动量 M-B (20,5) 为主、M-A (60,20) 为辅；反转 R-A (5,3) 为主、R-B (1,1) 为辅且必配"跳一日"版；250 日动量只作无条件腿，不进状态。窗口 $W$：M-B 200、M-A 750、R-A 50、R-B 40。阈值全部取草案值（$c_{in}=1.28$、$c_{out}=0.5$、$\kappa_0=0.5$、$K_I=l+h+2$、$C$ 取零分布 95% 分位）。

## 4. 通过标准（先写死，再看最终结果）

| 编号 | 标准 |
|---|---|
| A1 引擎 | 两套实现逐日最大差 < 1e-10；防偷看（篡改 t 后数据，t 及以前的所有变量、状态、权重不变）；恒等式精确成立 |
| A2 变量 | 空世界里 $\tau\approx N(0,1)$（均值≈0，标准差≈1，$P(\tau\ge1.28)$ 约 10%）；单一象限世界里样本 $\hat\rho$ 与 §7.3 闭式解同号且比值在 [0.5, 1.5] |
| A3 找回 | 长驻留世界（各象限平均驻留 300 日，$\Delta\rho=0.15$）：AUC($\tau_M$) ≥ 0.75，AUC($\tau_R$) ≥ 0.80；文档默认驻留世界只报告 |
| A4 无状态对照 | N0z、N0、N1、N2、N2b、N3、N4 下 Θ 判定规则的假阳性率 ≤ 5%（主参数 M-B/R-A） |
| A5 H5 对照 | 所有无状态世界（尤其 N2b"集中但公开"）H5 拒绝率 ≤ 5% |
| A6 N2 关联 | N2 中 $\delta^M,\delta^R$ 与 $z(V),z(\Phi^\perp),C$ 的 6 组关联检验拒绝率各 ≤ 5% |
| A7 延迟 | 主参数（M-B、R-A）首次越过 $c_{in}$ 的中位延迟 / 窗口版 $d^*$ 预测 ∈ [0.6, 1.5]；$d^*$ 下界与按规则取窗的变体只报告 |
| A8 功效 | 报告 $\Delta\rho$ = 0、0.05、0.10、0.15、0.20 的检出率、AUC、延迟（不设通过线，给出最小可检测效应） |

假阳性率用点估计与 Clopper-Pearson 95% 区间同时报告；点估计 ≤ 5% 记通过，区间下界 > 5% 记明确失败。
