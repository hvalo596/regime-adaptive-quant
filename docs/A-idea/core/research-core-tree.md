# 研究核心思想树：状态如何指导动量 vs 反转（期货，中国先行）

综合三源：①实验方案（`internal/research-proposal.txt`）②ieki 的思想（市场有效性、金融本质优先、期货；顺序已改为照实验文档中国先行，见 [thought-log](../meta/thought-log.md)）③Kai 老师微信（9/19，A 股建模约束 + 四维近似正交）。

一句话主线：**状态不是模型输出的标签，而是"谁在亏钱给我"的可观测代理；有效性随状态起伏，动量/反转的相对优势随之变化；先把状态定义到低维、可解释、与策略原理对齐，再谈 HMM。**

---

## 根：钱从哪里来？

> 策略赚的是谁的钱？什么条件下对手方消失？——能回答这个问题的状态划分才有经济含义（方案"注意点"第三条，与 ieki"金融本质优先"同一句话）。

- 动量赚：**反应不足 / 羊群 / 追涨杀跌**者的钱（信息慢吸收 → 正自相关）
- 反转赚：**急于成交者**的钱（提供流动性，赚回归补偿）
- 状态的作用 = 判断这两类对手方当前谁更多、谁在消失

## 第一层：机制（不是模型）

### 1. 有效性是动态的（AMH）
- 完全有效不可能（Grossman–Stiglitz）：超额收益 = 信息成本 + 风险补偿
- 适应性市场（Lo）：有效程度随参与者结构、竞争、环境起伏
- **课题定位**：研究的恰是"有效程度的变化"；市场变有效 = 状态间差异收敛，不推翻课题，只给出否定结论（同样有价值）
- 推论：**美国期货更有效 → 状态差异更小、更难显著；但一旦成立更有说服力**

### 2. 动量/反转的人性与制度来源（决定"何时灵"）

| | 来源 | 何时更灵 | 最怕 |
|---|---|---|---|
| 动量 | 反应不足、羊群、套利有限（Shleifer–Vishny） | 趋势持续、波动适中/下降、方差比 >1 | 大跌后高波动反弹（动量崩溃） |
| 反转 | 过度反应、流动性补偿 | 恐慌/流动性稀缺（补偿上升）、方差比 <1 | "超跌"其实是新趋势起点 |

**效率 ↔ 策略的联结（本项目核心假说骨架）**
- 信息扩散慢 / 套利成本高 / 羊群强 → 正自相关 → 动量占优
- 流动性冲击 / 资金受限 / 过度反应 → 负自相关 → 反转占优，但**单次风险同步放大**
- 效率很高、冲击被快速套利 → 两者溢价都趋零，状态间差异消失 → 应得到"否定结论"，此时退回波动率目标化类无状态基准
- 注意：反转的补偿与风险在同一状态一起升高，所以映射不能只看均值，要看**条件夏普 + 尾部**

### 3. 状态 = 可观测代理，不是黑箱 HMM 标签
- 好状态变量要能讲清"为什么这个状态下这类策略赚钱"
- 候选（方案 + 文献）：自相关/方差比、波动率水平与方向、流动性（量、价差、冲击）、趋势强度与分歧度、拥挤度、政策冲击
- **Kai 的四维是这条原则的具体落地**（见第二层）

### 4. 用市场结构差异检验机制（期货；中国先行）
- 对象：**期货**（可双向交易，两类策略都能真实执行；避开 A 股现货做空受限）
- **按实验文档先做中国期货**（股指/国债/商品；Tushare 日线已通）
- 美国期货后置，作独立验证 / 机制对照（更有效市场，差异更难显著但更有说服力）
- 检验逻辑：机制若成立，投资者结构不同，"状态→策略"对应关系应**按预期不同**，而非简单多一个样本

## 第二层：如何落地（Kai 的截图并入）

### A. 参数灾难 vs 样本稀缺
- Kai：A 股 2005 至今约 5000 日；8 维 × K=5 × 全协方差 ≈ **240 参数**（40 均值 + 5×36 协方差 + 20 转移）
- 更致命的是**有效样本 = 独立状态片段数，不是天数**：大的高风险阶段约 10 次，均值/协方差估不准
- 对本项目：方案原有 HMM 梯度（Gaussian→Student-t→sticky→HSMM）**保留为后期层级，但不作为起点**；先上规则型（分位数阈值），HMM 只在低维特征上跑
- 参数量对照：4 维、K=3、全协方差 ≈ 48；4 维、K=2、对角 ≈ 18

### B. 四维近似正交 + 策略驱动的自相关/方差比

| 维度 | 含义 | 为何有用 |
|---|---|---|
| 系统性风险水平 | 共同因子（市场/板块）波动 | 对应"波动率高低"，但被拆开 |
| 系统性方差占比 | 共同因子方差 / 总方差 | **≈ 相关性水平**，与水平分离 → 修正"相关性随波动机械上升" |
| 特质风险水平 | 残差波动 | 个体冲击强度 |
| 特质风险集中度 | 特质风险是否集中于少数资产 | 区分"普遍分散"与"局部事件" |
| ＋ 方差比 / 自相关 | 从策略原理直接推出（VR>1 利动量，<1 利反转） | 状态与策略盈亏机制**直接对齐** |

- 为什么好：①几乎正交，不重复计数同一波动 ②每维有金融含义，状态**天然可解释**（对应 ieki 要求）③低维，缓解 A
- 自相关/方差比的**周期要与策略回看/持有期匹配**，否则只是装饰变量

### C. 可解释状态 → 策略权重映射
- 路径：低维状态（阈值或低维 HMM 滤波概率）→ 各状态下策略条件表现 → **向整体估计收缩**的权重 → 不确定性惩罚（模糊则靠拢基准）→ 不动区间控制换手
- 必须对照：波动率目标化、风险平价、不建状态的在线学习（EWA）。若无状态方法追平，说明显式状态不必要

### D. 信息价值分解与失效模式（方案的最终产出）
- 三情形：无状态 / 实时滤波概率 / 上帝视角 → (3)-(1) = 状态理论价值，(2) 占其比例 = 方法效率；再拆"整体缩放"与"策略间重配"
- 核心数字：**状态平均持续期 ÷ 平均检测延迟**
- 五类失效：识别 / 时效 / 映射 / 执行 / 新颖性。Kai 指出的"稀有阶段估不准"直接对应**识别失效 + 新颖性失效**
- 只用滤波概率，不用平滑/Viterbi；多重检验修正；每个数字带置信区间

## Kai 的建议翻译成本项目（期货，状态自适应动量/反转）

**保留（KEEP）**
- 状态须低维、可解释、与策略原理对齐
- 把"波动率高低"拆成水平与结构（占比、集中度）
- 方差比/自相关作为直接服务动量-反转的维度
- 对稀有阶段样本的敬畏：把"独立片段数"当作有效样本量，报告它

**舍弃（DROP，朴素全协方差高维 HMM）**
- 8 维以上特征直接喂 K≥5 的全协方差 HMM
- 把 HMM 标签当真实状态、用平滑/Viterbi 做决策
- 用单一"波动率高低"或"相关性高低"当状态（二者机械联动）

**必须改写（不能照搬 A 股）**
- Kai 的"系统/特质"基于**股票截面**；期货截面窄（美期货约几十个合约，跨板块），特质风险集中度更噪。需先定义：系统因子 = 截面第一主成分/等权篮子，特质 = 残差；集中度用 HHI 或前 k 名占比，并检验稳定性（**待用户确认是否采纳此定义，或改用板块层级**）
- 数据长度不同：美国期货可追溯更久（含更多高风险片段，有效样本更好）；中国期货品种/起点不一，作对照时要接受样本更短
- "近似正交"需**经验验证**（相关矩阵、VIF），不能预设

**待检验假说（方向未定，勿当结论）**
- 系统性占比高 + VR>1 且波动下降 → 动量条件夏普更高
- 特质集中度高（局部事件）+ 流动性紧 → 反转补偿高但尾部风险大
- 系统性风险水平极高 → 两类策略都应降仓位（这部分多半被波动率目标化吃掉，要分离）

## 第三层：近期怎么做（先机制、后代码、省额度）

1. **先定义（不写代码）**：四维 + 方差比的精确公式、期货截面构造、与动量/反转策略的周期匹配；写成一页"状态词典"，每个状态配"谁在亏钱给我"的一句话
2. **先写假说表**：每条假说 = 状态条件 + 预期方向 + 经济理由 + 证伪标准（便于否定结论）
3. **美国期货最小可行实验**（顺序不变，方案第 1–2 步）
   - 合成数据：2–3 个已知状态，另有"无状态"空跑，验证管线不会凭空找状态
   - 固定 TSMOM + 短期反转（参数锁死，对象是配置机制）
   - **条件分组分析**（四维分位数分组，block bootstrap 置信区间，只用当期及以前数据）——这一步不用 HMM
   - 先看"组间差异是否显著且足够大"，再决定是否值得上 HMM（低维、K=2–3）
4. **中国期货（Tushare）**：只复用同一状态词典与代码，作机制对照；比较"状态→策略"方向是否按投资者结构差异变化
5. **暂不做**：高维 HMM、变点检测、EWA 以外的复杂对照；这些在第 3 步显示"存在性"后再上
