## 0. 先说读法：四维为什么值钱（ieki 最新的认识）

ieki 的体会：以前觉得老师"给得少"，以为模型才是关键；现在看到，**真正重要的是金融解释**。这正是本文的主线：

- Kai 的四维**不是一个更花哨的模型**，它甚至一行模型都没有。它的价值是一种**约束**：逼你把"市场状态"翻译成**能讲清楚谁在亏钱给谁**的金融量。
- 所以评判一个状态变量好不好，第一标准不是"拟合得多好"，而是三问：
  1. 它在测市场里**哪一种具体的东西**？（系统风险？分散还是集中？）
  2. 这个量变大/变小，对**动量的对手方（慢人）**和**反转的对手方（急人）**意味着什么？
  3. 它变了，我能不能**事后讲清楚**策略为什么赚/亏？（这决定第 6 步能不能做"映射失效"的归因）
- 反例：把 20 个指标丢给黑箱聚类，拟合再漂亮，答不出这三问，就是"舍本逐末"（ieki 02:52 的原话方向）。四维用很少的几个量就答得出，这就是老师那几句话的分量。

## A. 刑凯四维（重头戏）

### A0. 先看整体：为什么是"拆开"

传统做法：看"波动率高低"一个数。问题是它把几件完全不同的事混在一起：

- 全市场一起抖（宏观/政策/恐慌）；
- 每个品种各自抖（各讲各的故事）；
- 少数品种抖得特别厉害（局部事件）。

这三种情形对**谁在场、谁在亏钱**的含义完全不同，但"波动率高"一个词全盖住了。四维就是把这一个词**拆成三个有含义的问题**：

| 问题 | 对应维度 |
|---|---|
| 共同的部分有多大声？ | ① 系统性风险水平 |
| 共同的部分占整体多少？（≈大家多同步） | ② 系统性方差占比 |
| 各自单独的部分有多大声？ | ③ 特质风险水平 |
| 单独的部分是撒得很匀，还是堆在少数几个上？ | ④ 特质风险集中度 |
| 惯性多还是回弹多？（直接从策略原理来） | ⑤ 方差比 / 自相关 |

（Kai 说"四个近似正交的维度，再加上从策略原理推出的自相关结构"，所以是 4+1。）

> 记号约定（草案）：把各品种收益拆为 `r_i = β_i·f + e_i`，f 是共同因子（等权篮子或截面第一主成分，待确认），e_i 是残差。S = 共同因子方差，I = 残差方差（按品种汇总）。

### A1. 系统性风险水平

- **白话**：整个市场（或板块）**一起**涨跌的幅度。大家一起晃得有多厉害。
- **测什么**：共同因子 f 的波动（草案：S 的平方根或其对数，用滚动窗口估计）。
- **不测什么**：不测每个品种自己的故事；不测"大家是不是同步"（那是②）。
- **跟赚钱机制的连接**：系统性波动极高 = 宏观/政策/恐慌冲击在主导。这是**动量崩溃**（大跌后高波动反弹）和**强平踩踏**（反转补偿厚、但尾部风险同步放大）发生的温床。它告诉你"大冲击在不在"，不告诉你"该顺势还是逆势"。
- **和"只看波动高低"的差别**：总波动 = 共同部分 + 各自部分，只看总数会把"各品种各自吵"也算成"市场很危险"。①把"共同部分"单独拿出来，才对应系统性冲击。
- **要警惕**：很多"状态切换有用"，其实只是高波动时降仓（波动率目标化一行代码就能做）。①这一维最容易被无状态基准吃掉，第 4 步必须专门分离。

### A2. 系统性方差占比（最关键的一维）

- **白话**：总波动里，"一起动"占多大比例。越高越"步调一致"，约等于**相关性水平**。
- **测什么**：草案 `share = S/(S+I)`（也就是共同因子对截面方差的解释比例，R²）。
- **不测什么**：不测波动绝对大小。

**它如何拆开"波动一高相关就跟着升"的假象？** 这是 Kai 那句"修正相关性随波动机械上升"的核心。看两个品种的相关性（草案推导）：

`ρ = β₁β₂S / √[(β₁²S+σ₁²)(β₂²S+σ₂²)]`

如果只是共同因子的波动 S 变大，品种自己的残差 σ² 和对共同因子的敏感度 β 都没变，**ρ 也会机械地上升**——因为共同部分"声音变大"了，盖过了各自的声音。结果就是：

- 你在高波动期看到"相关性升高"，就以为"大家的关系变紧了、传染了、分散化失效了"；
- 实际上可能只是**同一个系统性冲击音量变大**，结构（β、残差）没变。

（这和金融里"以高波动为条件算出的相关性会被高估"的老问题同一个来源，常被引用为 Forbes–Rigobon 一类讨论；这里只借其直觉，不当结论引用。）

四维把它拆成**两个互相交代清楚的问题**：
- "音量大不大"→ ① 系统性风险**水平**；
- "共同声音占整体多大比重"→ ② **占比**。

于是"相关性升高"可以被归因：是 **S 变大**（纯音量），还是 **I 变小**（各自安静了、共同占比自然高），还是**占比在 S 和 I 都不变的前提下上升**（这才更像β抬升、真正的"同步增强"）。

> ⚠️ **一个必须正面处理的数学事实（我的发现，待与 Kai 对齐）**：若①②③都按上述同口径定义，则 `share = S/(S+I)` 是①和③的**函数**，即三个量只有**两个自由度**；取对数后 `log(share/(1−share)) = log S − log I`，是**线性依赖**。所以"近似正交"**不能指代数上独立**，只能指：（a）在样本中三者经验相关不太高；或（b）Kai 的定义口径不同（例如不同窗口、标准化、或占比用别的口径）。这点要靠 VIF/相关矩阵实测，并问清 Kai 的原定义。**不能预设"四维正交"，更不能把三个依赖量同时当独立特征喂进模型**（D 节第 2 条）。

- **跟赚钱机制的连接**：占比高 = 品种同涨同跌（"一个故事"主导），截面上赚不到"品种间差异"的钱，趋势/恐慌由共同因子驱动；占比低 = 各品种讲各自的故事，局部事件多。同一个"波动高"，占比高低意味着**完全不同的对手方画像**。
- **和"只看波动高低"的差别**：波动高低只回答"音量"，占比回答"是几个声部在合唱还是各唱各的"。

### A3. 特质风险水平

- **白话**：每个品种**剔除共同部分后**，自己单独的波动有多大。
- **测什么**：残差 e_i 的波动（草案：各品种残差方差的平均或中位数）。
- **不测什么**：不测共同冲击；不测残差是否集中（那是④）。
- **跟赚钱机制的连接**：特质波动高 = 各品种自己的信息冲击多（供需、政策、事件）。信息冲击多且被慢慢消化 → 动量空间；但也意味着"超跌"更可能是**真实的新信息**（反转的"接飞刀"风险）。特质水平低 = 品种像被共同因子牵着走，品种间可交易的差异少。
- **和只看波动的差别**：把"真有新信息"（各自的故事）与"大家一起晃"分开，这对反转尤其关键：反转能不能收到"急人"的补偿，取决于跌的是流动性冲击还是特质信息。

### A4. 特质风险集中度

- **白话**：这些"各自的波动"是**撒在很多品种上**（普遍不安），还是**堆在少数品种上**（局部事件）。
- **测什么**：草案——残差方差份额的赫芬达尔指数 HHI（或前 k 名品种占比、或 1/HHI 等价"有效品种数"）。
- **不测什么**：不测总量；不测是哪一个品种（那属于事件识别，不是状态）。
- **跟赚钱机制的连接**：集中 = 局部事件（某品种的政策、供给冲击、挤仓）。局部事件里，对手方往往是**知情者**，反转容易接飞刀；分散 = 普遍性的不确定，更像情绪/流动性层面。这是区分"流动性补偿"与"信息冲击"的一把尺子。
- **和只看波动的差别**：总波动相同，"一个品种暴雷"与"所有品种都躁动"是两回事，只看波动区分不开。
- **期货落地注意**：Kai 的设计来自**股票截面**（几千只）。期货截面很窄（中国股指期货约 4 个、国债期货约 4 个、商品几十个，数字待核实），HHI 的下限 `1/N` 本身就很高，**一个品种的噪声就能把集中度带偏**。需要决定：是否只在商品板块内算集中度？或改用板块层级？见 D。

### A5. 方差比 / 自相关（"从策略原理推出的那一维"）

- **白话**：这一周期里涨跌是"有惯性"还是"会回弹"。
- **测什么**：Lo–MacKinlay 方差比 `VR(q) = Var(q日收益) / (q × Var(1日收益))`。VR>1 → 正自相关 → 利动量；VR<1 → 负自相关 → 利反转。
- **不测什么**：不测波动大小（它是比值，天然把水平除掉了，这也是它与①–④近似正交的原因）。
- **跟赚钱机制的连接**：动量赚的就是正自相关，反转赚的就是负自相关。**这是四维里唯一直接是"策略利润来源"的一维**，其余四个是在判断"为什么"和"在什么环境"。
- **为什么周期必须与策略对齐**：动量的回看/持有期若是 20–60 日，用 1–2 日的自相关来判断是在答非所问；反转若看 1–5 日，用 60 日方差比同样无关。周期错位，这个变量就只是"装饰变量"。所以 q 要**从策略参数反推**（而策略参数第 2 步起已锁死）。
- **没有它会怎样**：①–④只告诉你环境，没人告诉你**该偏哪个策略**；只有 VR 能把状态直接指向"动量 or 反转"。
- **需要注意**：VR 在 q 大、样本短时很噪、且滚动窗口会重叠；还需确定它算在**什么收益上**（共同因子收益？各品种平均？策略组合自身？）——待确认。

### A6. 为什么四维要"近似正交"，又为什么要和策略周期对齐（合起来讲）

**为什么要正交（至少经验上低相关）**
1. **不重复计数同一件事**：若几个特征本质都是"波动高低"，聚类/HMM 只会学到第一主轴，即"高波动 vs 低波动"，你的"状态"又退化成了波动率状态，第 4 步里**波动率目标化**一行代码就把你吃掉。
2. **每一维有独立的金融含义**，才能写成"状态 = 一句人话"（见 C）。
3. **低维缓解样本稀缺**：Kai 的 240 参数警告——8 维 × K=5 × 全协方差。有效样本是**独立的高风险片段数（约十来次）**，不是天数。维度越少越冗余越少，参数越少，才估得动。（草案对照：4 维 K=3 全协方差约 48 参数，4 维 K=2 对角约 18。）

**为什么还要加 VR/自相关（而不是只留四维）**
- 四维是**环境**，VR 是**策略利润的直接来源**。只有环境没有利润项，状态与"动量 or 反转"之间没有直接桥梁，映射会靠事后拟合凑出来（第 6 步的"映射失效"就会难以排查）。

### A7. 与 ieki 新认识的对应

四维把"波动高低"逼成"谁在场"：
- ①②：系统性冲击大不大、步调齐不齐；
- ③④：信息冲击是普遍还是局部；
- ⑤：惯性还是回弹。

每一个回答，都能直接落到"慢人多还是急人多、对面是不是知情者"，这就是 ieki 说的"金融解释"。**价值在于被迫解释，不在于更高级的拟合。**

## B. 实验 6–7 步：每一步为什么必须有

> **编号对照**：方案原文是**开头（推导状态变量）+ 第一步至第六步**。若把"开头"算作**第 0 步**就是 **7 步**，否则 6 步（D5 请 ieki 定称呼，不影响内容）。下文按 0–6 编号。

### 整条链的逻辑（先看这一段）

```
0 状态变量从机制推出来（不是从模型里"长"出来）
1 搭实验场 + 先在已知答案的假世界里排练（防工具骗人）
2 证明：状态存在，且对策略盈亏有用（不用复杂模型）
3 证明：状态能及时认出来（不是事后诸葛）
4 证明：认出来后真能赚钱，且赢过简单对照（不是"状态"在偷偷等于"降仓"）
5 证明：不是数据挖掘 / 运气 / 泄露（防自欺）
6 失败怎么分类（诚实地说它在哪里会坏）
```

每一环只在前一环成立时才有意义；任何一环失败，**都是有价值的否定结论**，不是项目失败。

---

### 第 0 步：从机制推出状态变量（方案开头）

1. **问什么**：该看哪些变量，才与"动量赚慢人钱、反转赚急人钱"对得上？
2. **跳过会怎样**：直接让模型"发现状态"→ 得到一个无法解释的标签，对不上赚谁的钱；后面所有结论都说不清"为什么"，第 6 步的映射失效无从归因。
3. **与"赚谁的钱 / 可观测性"**：此步就是把对手方画像翻译成**可算的量**。四维＋VR 在这里落地。**可观测性**意味着变量只能用当期及之前的数据算。
4. **内部关键点**：①每个变量配一句"谁在场"；②写**可被否定**的假设（如"VR>1 且波动下降时，动量条件夏普更高"），含证伪标准；③变量要近似正交、低维。

### 第 1 步：搭实验环境（资产 / 回测 / 合成数据）

1. **问什么**：我们的"尺子"可靠吗？在**答案已知**的世界里，这套流水线能不能找回答案；在**根本没答案**的世界里，会不会编造答案？
2. **跳过会怎样**：不选可双向交易品种 → 反转只剩半边；回测偷看未来或忽略换月/成本 → 凭空造假收益；没有合成数据 → 真实数据上"找到"或"没找到"，都无法判断是方法的功劳还是方法的缺陷（假阳性、不可解释）。
3. **与"赚谁的钱 / 可观测性"**：合成数据里的"状态"是我们**设定**的对手方画像（如状态 A 正自相关=慢人多，B 负自相关=急人多），先验证方法能否**在已知对手方变化时**认出来。
4. **子模块各防什么坑**：
   - **资产选择**（中国股指/国债/商品期货）：可双向 → 两类策略都能真实执行。
   - **回测系统**：时点正确防"未来函数"；换月处理防"换月跳变"变成假收益；成本模型（手续费＋与波动/成交量挂钩的滑点）决定高换手的反转还剩多少；向量化＋逐笔事件两套互相核对，防**实现 bug**。
   - **合成数据**（见下，是整条链里最不可替代的一块之一）。

**为什么合成数据不可替代？** 真实数据没有"标准答案"。三种结果在真实数据上**互相不可区分**：真没有 / 方法没找出来 / 过拟合编出来。合成数据把"答案"变成已知，这三者才能区分。

**为什么"无状态对照"不可替代？** 它是安慰剂组：让模型去找一个**本来就没有状态**的随机序列，看它会不会"发现 2 个状态且策略在不同状态下表现不同"。若会，说明方法**制造幻觉**，后面所有"发现"都要打问号。没有这一组，你永远不知道"幻觉率"。

### 第 2 步：检验存在性（简单策略 + 条件分组，完全不用 HMM）

1. **问什么**：按可观测状态分组后，动量和反转的**条件表现差异**，是否显著、是否足够大？
2. **跳过会怎样**：若直接上 HMM → 就算分组本身没差异，HMM 也会（按设定）给你几个状态，还给你"拟合很好"的错觉；这是整个项目最大的假阳性来源。
3. **与"赚谁的钱 / 可观测性"**：第一次用数据检验"对手方多的状态里，对应策略真的更赚"。这里**只用当期及之前的数据**，状态是可观测的。
4. **子模块各防什么坑**：
   - **锁死策略参数**（时间序列动量、短期反转、可选 carry）：课题研究的是**配置机制**，不是调参；同时调参会让你分不清好结果来自状态还是调参。
   - **条件分组**（四维分位数、VR 分档）：不依赖模型的**最朴素存在性检验**。**实现提醒（我的建议）**：分位数阈值要用**滚动/扩展窗口**估计，而不是全样本分位数，否则等于偷看未来。
   - **block bootstrap**：金融数据前后相关，按一天一天乱抽会低估误差；成块抽样给出诚实的置信区间。
   - **报告独立状态片段数**（承接 Kai 的警告）：有效样本是片段数，不是天数。

### 第 3 步：检验可预测性（规则 → HMM → 持续性 → 变点，逐层加）

1. **问什么**：当下（只用此刻之前的数据）能多快认出状态？
2. **跳过会怎样**：第 2 步的分组是**事后**看整体统计；不检验识别延迟，会把"事后诸葛"当可用信号 → 回测漂亮，实盘认出来时状态已结束（时效失效）。
3. **与"赚谁的钱 / 可观测性"**：对手方是**一段一段出现**的；认得太慢，补偿已被别人收走。可观测性在这里被量化成一个数字：**平均持续期 ÷ 平均检测延迟**。
4. **子模块各防什么坑**：
   - **规则基准**（分位数阈值）：先知道最简单的办法能到哪里，后面每层复杂度必须证明边际贡献。
   - **HMM（高斯→Student-t）**：重尾处理，防止极端日被误判成新状态；也是在**低维**特征上跑，回应 Kai 的参数灾难。
   - **持续性约束（sticky HMM / HSMM）**：防状态来回乱跳（无意义换手）。
   - **变点检测**：不预设状态个数，换个角度防"状态数设错"。
   - **只用滤波概率**：平滑/Viterbi 用了未来，只能事后分析，进回测就是作弊。
   - **滚动重估时的标签对齐**：防"状态 1/2 编号互换"造成的假切换，并记录对齐不稳定的频率。
   - **检测延迟（合成数据上直接测）**：把"识别"与"时效"拆成两个独立可测的量。

### 第 4 步：检验可盈利性（认出来之后怎么配权重）

1. **问什么**：认出状态之后，扣掉成本、考虑不确定性，**真的比简单办法赚得更多吗**？
2. **跳过会怎样**：只证明"能认出"不等于"能赚钱"；而且状态的好处常常是**换了个名字的降仓**（高波动少买点）。不做对照，会把"波动率目标化的功劳"错记在"状态识别"头上（无法归因）。
3. **与"赚谁的钱 / 可观测性"**：概率加权承认"我不确定现在对手是谁"；不确定性惩罚=没把握就少下注；不动区间=认出来也不一定值得换，要扣成本。
4. **子模块各防什么坑**：
   - **无状态基准**（等权、风险平价、波动率目标化）：防"复杂模型≈一行代码"。
   - **概率加权 + 向整体估计收缩**：每个状态样本少，直接用状态内最优权重会过拟合。
   - **不确定性惩罚**：防"判断模糊时仍重仓"。
   - **完全绕过状态的在线学习（EWA 等）**：最狠的对照。若它追平，**显式识别状态就是多余的**。
   - **不动区间/部分调仓**：防白付手续费，成本越高越"懒"。

**为什么"信息价值三档"不可替代？** 三档是：①无状态 ②实时滤波概率 ③上帝视角（知道真实状态）。
- ③−① = **状态这个概念本身值多少钱**（理论上限）；
- ②−① 占 ③−① 的比例 = **我的识别方法拿到了多少**（效率）。

只有三档并排，才能把"没赚到钱"归因到**两种完全不同的原因**：状态本身没价值（③≈①，说明对手方起伏对策略选择帮助不大，**市场可能很有效**），还是状态有价值但认不出来（③≫①而②≈①，问题在识别）。再进一步拆成"整体仓位缩放"与"策略间重配"：只有后者才是"状态指导选策略"，前者可能被波动率目标化抢走。

### 第 5 步：稳健性与失效分析（防自己骗自己）

1. **问什么**：前面的好结果，会不会是泄露、运气或试出来的？
2. **跳过会怎样**：试了几百种组合挑最好那个，"最好"多半是运气；训练/测试紧挨着则信息泄露。这时前四步所有结论**都不可信**（假阳性、无法证伪）。
3. **与"赚谁的钱 / 可观测性"**：打乱状态标签后收益消失，才能证明收益确实来自"对手方变化"这个信息，而不是别的东西。
4. **子模块各防什么坑**：
   - **隔离期**：防滚动窗口里相邻样本互相暗示。
   - **记录试验次数 + 缩减夏普（多重检验）**：防"选择偏差"。
   - **切换期行为分析**：看系统在"最关键时刻"到底做了什么。
   - **历史压力情景**：不同类型冲击（流动性踩踏、政策跳跃、全球恐慌、长期窄幅磨损）暴露不同失效。
   - **人为压力测试**（加延迟、打乱标签、制造"切换快于检测"的市场）：找方法**完全失效的边界**。

### 第 6 步：失效模式分类

1. **问什么**：这套东西**在哪一环会坏、什么条件下坏**？
2. **跳过会怎样**：只有"成功/失败"两个结局，学不到东西；失败了不知道坏在识别、时效、映射、执行还是新颖性，就没法改进，也没法向业界讲清楚边界。
3. **与"赚谁的钱 / 可观测性"**：五类失效其实是五种"对手方画像出了问题"（见白话文档表格）。**这里四维的"可解释"价值最大**：映射失效只有在状态**可解释**时才查得出原因（同样的状态，这次对手方行为变了），黑箱标签只能耸耸肩。
4. **五类**：识别（噪声当状态）、时效（认得太晚）、映射（状态→策略关系变了）、执行（成本/流动性/拥挤吃掉）、新颖性（没见过的状态硬塞旧标签；对应 Kai 说的"稀有阶段估不准"）。

### B-总表：几件"不可替代"的东西为什么不可替代

| 东西 | 唯一能回答的问题 | 缺了会犯的错 |
|---|---|---|
| 合成数据（已知状态） | 方法能否找回已知答案 | 真实数据上无法区分"真没有/没找到/编出来" |
| 无状态对照 | 方法会不会凭空找状态 | 幻觉率未知，所有"发现"不可信 |
| 无状态基准 + EWA | 显式状态是否真的必要 | 把降仓/近期表现的功劳误记给"状态" |
| 信息价值三档 | 状态值多少钱 / 我拿到多少 | 失败原因无法归因（概念无价值 vs 识别不行） |
| 滤波概率 + 检测延迟 | 能否及时认出 | 事后诸葛，实盘不可用 |
| 多重检验 + 打乱标签 | 是不是运气/泄露 | 数据挖掘出的假阳性 |
| 失效分类 | 在哪一环坏 | 失败后学不到东西 |

## C. 状态词典草稿（短，全部**示意**）

> 用"四维 + VR"读成一句人话。下表只写**方向**，不写具体数值阈值，也不是实证结论，都要靠第 2 步数据检验或否定。

| 示意状态 | 读法（①系统水平 / ②占比 / ③特质水平 / ④集中度 / ⑤VR） | 人话：谁在场 | 假设方向（待检验） |
|---|---|---|---|
| **慢人多（趋势消化期）** | ①中或下降 / ②中高 / ③低 / ④低 / ⑤VR>1 | 新信息被慢慢消化，追涨者、拆单大资金还在进场 | 动量条件夏普更高 |
| **急人多（恐慌/流动性冲击）** | ①高 / ②高 / ③中 / ④低 / ⑤短周期 VR<1 | 强平、恐慌抛售，需要出口 | 反转补偿厚，但尾部同步放大，要看条件夏普+尾部 |
| **高系统风险但低相关** | ①高 / ②**低**（③必然也很高） / ④低 / ⑤不明 | 全面躁动，但各品种各讲各的故事（如多个商品同时遇到各自的供给/政策冲击） | 两类都没明确优势，更依赖 VR；降仓 |
| **局部事件（特质集中）** | ①低 / ②低 / ③高 / ④**高** / ⑤个别品种 | 少数品种出事，对面可能是知情者 | 反转易接飞刀；按品种而非按全市场处理 |
| **平静无结构** | 全部低，VR≈1 | 慢人和急人都不多（对手方消失/市场更有效） | 两类溢价趋零；退回无状态基准——否定结论候选 |

两点说明：
- 第三行的"高系统风险低相关"能同时出现，**只因为占比不是单独的"相关性"，它也取决于特质水平**（回应 A2 的数学依赖）。
- 这里**没有"动量崩溃状态"一行**：它很可能是"高系统水平 + 突然反转"的**动态**，不是静态读数，要在第 5 步的切换期分析里单独看。

## D. 待向 ieki 确认的问题（少而硬）

1. **系统因子怎么定？** 全部期货取截面第一主成分？还是**分板块**（股指 / 国债 / 商品，商品内再分能源/金属/农产）？中国期货里股指和国债品种数很少，混进商品里可能被商品主导。
2. **四维的口径与正交**：Kai 的原定义（邮件资料）能否拿到？在我们的草案里 `①、②、③` 只有两个自由度，要不要以"②为派生量、只在映射解释里用，不当独立特征"处理？
3. **特质集中度**：品种数很少时 HHI 很噪。可接受的退路是——只在商品板块内算，还是改用板块层级的集中度？
4. **方差比周期 q**：要等 ieki 确认锁定的动量/反转**回看期与持有期**（锁定后才能定 q）。有倾向值吗？还是我先给 2–3 组候选？
5. **步数叫法**：对外称"6 步（方案原文）"还是"7 步（含开头第 0 步）"？
6. **截面范围**：股指、国债是否与商品**同一截面**？还是先**只做商品**以保证截面一致，股指/国债作单品种的对照？
7. **估计窗口与频率**：日频，滚动窗口多长（需与状态预期持续期匹配）？允许在第 2 步先用 2–3 个候选窗口，但要计入"试验次数"（第 5 步多重检验）。
8. **否定结论的底线**：若第 2 步分组差异不显著，ieki 是否同意"直接止步并写否定结论"，而不是再加复杂模型去找？（这决定第 3–4 步是否启动。）
