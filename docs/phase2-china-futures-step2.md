## 检验对象与流程（对应实验文档第 2 步）

- D = 动量腿/其事前波动 − 反转腿/其事前波动（沿用阶段 1；单位是事前 σ，所以 D 的"年化收益"列不是收益率）。策略参数仍是 **TO_LOCK 草案**（60/20、5/3）。
- 代理：VR 短/长 + 四维草案（滚动窗口 60 日），共 6 个，**先只在商品面板上**；股指/国债作单品种对照留到下一步。
- 分档：扩展窗口三分位，t 日标签配 t+1 日 D。
- 每个代理给出：高档−低档 D 差；平稳 block bootstrap 95% CI 与 Bonferroni 校正 CI；**按状态片段**的 bootstrap（有效样本是片段数）；**循环平移零假设**（标签相对 D 随机平移，保持标签粘性）；每档片段数。
- **无状态零假设（流程级）**：把整个面板按块（平均 20 日）联合重抽样，重跑 腿→D→代理→分档→统计量，得到"持续性超过块长的状态都不存在"时的统计量分布，给出逐代理 p 与按 max|z| 的族群 p。
- 稳健性：剔除涨跌停代理日及其次日；前后半样本；块长 10/60。
- **事先写定的方向**（真实数据前写下）：vr_short/vr_long：+（VR>1 利动量）；sys_level/sys_share：−（恐慌/流动性状态，反转被补偿）；idio_level/idio_conc：+（信息冲击、接飞刀）。四维方向是草案里最弱的部分，反向显著会如实标出。
- 判据（沿用草案，待 ieki 确认）：预期方向一侧 CI 不含 0 且两端各 ≥5 个片段。

## 刑凯四维草案（**不是 Kai 的公式**）

r_i = β_i f + e_i，f = 当日有效品种等权均值；S = mean(β²·var f)，I = mean(var e_i)（用 OLS 恒等式得残差方差）。
① sys_level = ½log S；② sys_share = S/(S+I)；③ idio_level = ½log I；④ idio_conc = 归一化 HHI（0 = 完全均匀，1 = 全压在一个品种上）。
已用测试固定的事实：logit(②) = 2(①−③) 精确成立（自由度只有 2，样本 VIF 很高），所以不能把①②③当三个独立特征。单一等权篮子因子、窗口、归一化方式都待 Kai 原定义/ieki 确认（D1–D3）。

## 数据旗标与已知口径

- **收益一律用收盘价**，结算价只能用于保证金/成本。
- **涨跌停**：fut_daily 没有涨跌停表，所以只做代理（一价日 + 幅度），不是精确触板；有了交易所的板幅时间表再替换。
- **夜盘**：Tushare 把夜盘归到下一交易日，收盘到收盘仍自洽，但有夜盘的品种其"日"跨晚上到下午，跨品种对齐有隔夜偏斜。`night_draft` 的起始日期是**凭记忆写的未核实草案**，只能用于前后分样本，不能当排除规则；股指期货 2015-09 限制期日期同样未核实。
- **官方映射的时点性**：假设 t 日映射用 t 日收盘后已知信息；若实测发现映射含次日信息，把 `--roll-rule oi` 设为默认。
- 面板是不平衡面板（品种上市时间不同）；股指/国债不在商品截面里。

## 合成兜底结果（`artifacts/phase2_synthetic/{regime,null_const,null_volonly}`，16 品种、约 2500 日、单种子）

只证明管线行为，**不是证据**：

| 场景 | 现象 |
|---|---|
| regime（有已知状态） | vr_short / sys_level / sys_share 通过校正后的判据；vr_long 因低档仅 4 个片段不通过；idio_level 方向与预设相反，标为"反向显著"；展期 11.6 次/年，面板里无 D 分母爆炸 |
| null_const（无状态） | 6 个代理全部不通过，流程级零假设 p 全 >0.1 |
| null_volonly（只改波动与共同成分） | **仅靠 block-bootstrap CI，sys_share 仍"通过校正判据"（假阳性）**；循环平移 p=0.115、流程级零假设 p=0.12、族群 p≥0.19 都没有放行 |

第三行是本阶段最该注意的发现：**CI 判据单独使用，在粘性标签下偏宽松**。建议把"循环平移零假设 p<0.05（或流程级 p<0.05）"并入第 2 步的止步判据——这是对 ieki 的建议，不是已改规则。regime 场景里流程级 p 也只有 0.05–0.07（该零假设保留块内的波动结构，偏保守）。

## 阻塞与怎么跑真实数据

1. **缺 `TUSHARE_TOKEN`**：本次运行环境的环境变量里没有（项目约定它放 Cursor 控制台 secret）。Tushare 官网可连通。需要把官方 token 以 secret/环境变量注入后：
   ```bash
   python scripts/fetch_tushare_futures.py --group commodity --start 20100101   # 可断点续拉
   python scripts/run_phase2_existence.py --raw-dir data/raw --out artifacts/phase2_real
   ```
2. **积分/权限**：按 `tushare-access-check`，日线、映射、基础信息、持仓排名均可用，**没有积分挡路**；只有分钟线无权限（本阶段不用）。每个合约 1 次 `fut_daily`，商品全品种自 2010 起粗估近万次调用，150 次/分约 1 小时量级（估算，未实测）；`fut_holding` 单次 4000 行会截断（脚本会告警），本阶段不用。
3. 不要使用第三方转售 token 或把请求指向非官方域名：数据可能被改动、token 会外泄，并且会破坏本课题"每个数字可核对"的前提（见项目答复）。`TushareConfig.endpoint` 虽可改，仓库默认且只应使用官方地址。
