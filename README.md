# regime-adaptive-quant

基于市场状态切换的量化策略自适应机制研究（期货；**中国期货先行，美国后置**）。

核心问题：能否通过识别市场状态，在**动量**与**短期反转**之间做出有信息量的配置？
这里不是为了找一个更花哨的模型，而是先检验金融机制：动量收的是"慢人"的迟到费，反转收的是"急人"的加急费，两者的强度会变、有粘性、当期可观测、来得及交易。四个环节（C1–C4）任一断掉都是一个具体的否定结论。

当前进度：**阶段 1（回测框架 + 合成数据）已完成；阶段 2（中国期货接入 + 实验第 2 步）管线已完成，真实数据待 `TUSHARE_TOKEN` 注入后运行**，见 [docs/phase2-china-futures-step2.md](docs/phase2-china-futures-step2.md)。

## 设计要点（对应已钉死的思想）

- **检验对象是风险标准化价差 D** = 动量收益/其事前波动 − 反转收益/其事前波动。两腿先各自风险标准化，所以"高波动时降仓"从定义上被排除；D 在状态间若还有差异，只能来自"该选哪个策略"。
- **点时间一致**：信号用到 t 日收盘；仓位在 t+1 才赚钱；波动率估计只用过去；分档阈值是**扩展窗口分位数**（不用全样本分位数）；分档标签与次日 D 配对。测试里改动未来数据，已断言过去的权重/代理/分档不变。
- **收益一律是收盘到收盘**，不用结算价（真实数据阶段的要求，合成数据里同样沿用约定）。
- **合成市场**（`synthetic.py`）：粘性马尔可夫链切换三个状态，状态已知：
  - `slow`（慢人）：持续漂移 → 动量赚；
  - `rushed`（急人）：高波动、高共同成分、负自相关 → 反转赚；
  - `calm`：近似有效。
- **无状态对照**（安慰剂，用于区分"真没有"和"方法编出来"）：
  - `null_const`：参数恒定，取三状态均值，无状态；
  - `null_volonly`：状态只改波动和共同成分，策略优势（漂移/自相关）取均值——专门检验"只是降仓"不会被 D 当成状态。
- **基准**：等权持有篮子、等权 50/50、风险平价（腿波动倒数加权）、波动率目标化；另有**上帝视角**（按真实状态手工映射，仅合成数据可用，不是拟合出来的）作为信息价值上限的雏形。
- **不含**：HMM/变点（第 3 步）、EWA、概率加权配置（第 4 步）、真实换月、涨跌停、夜盘。

## 阶段 1 结果（合成数据；方向性检查，不是研究结论）

20 个种子、各场景每次检验 2 个代理（1 组参数）：

| 场景 | 代理 | 通过率 |
|---|---|---|
| regime（有状态） | vr_short / vr_long | 100% / 95%（找回率） |
| null_const | vr_short / vr_long | 0% / 0%（幻觉率） |
| null_volonly | vr_short / vr_long | 0% / 5%（幻觉率） |

要注意的观察（均为草案参数下，勿过度解读）：

1. 流水线能在已知状态里找回差异，在两种无状态数据上基本不"发明"状态。这是 C3 的方法部分（实验文档第 1 步）。
2. 代理对已知状态的区分度一般（AUC：急人≈0.76，慢人≈0.62），因为状态平均只持续约 50 日、而代理窗口 60–120 日——这是第 3 步"持续期 ÷ 检测延迟"要正面量化的东西。
3. 在草案成本下，反转腿净值长期为负，"上帝视角"（慢人→动量、急人→反转、平静→空仓）并没有比单纯动量更好：急人状态里的反转毛收益大多被成本吃掉。这是执行失效（第 6 步）的一个雏形，同时也说明反转的持有期和成本参数必须在锁定前认真对待。
4. `calm` 状态下 D 为正，主要是反转腿成本导致，而不是动量更赚。分析时需同时看毛 D 与净 D（`pipeline.ScenarioResult.d_gross/d_net`）。
